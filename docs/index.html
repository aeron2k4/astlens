astlens

AST-aware code navigation for AI coding agents.

A small, fast MCP server written in Rust. It uses tree-sitter to index symbols and trims file contents to a token budget, so agents can explore large codebases without reading whole files.

Whole files are the expensive way to read code

Agents that open file after file burn their context window on code they never use. astlens answers with the exact slice that matters — an outline, one definition, the references that are real code — each trimmed to a token budget you set.

Reading whole files

The default in most agent setups today.

one source file100% of tokens
  • Context fills with unrelated functions and imports
  • Text search matches comments, strings and docs
  • No map of the codebase — the agent wanders

Reading through astlens

Measured on the Go standard library — see benchmarks below.

file outline19% of tokens
one function (median)0.9% of its file
  • Outlines carry signatures and line ranges, not bodies
  • find_references skips comments and strings — 49% fewer lines than grep -w
  • codebase_map ranks what the rest of the code actually uses

15 tools, one server

Everything an agent needs to navigate and edit a codebase — and nothing that makes it read a whole file to do it. Paths are relative to the workspace root; read-only tools can also look into dependency sources (Cargo, Go module cache, node_modules, system headers).

Install in two steps

Prebuilt binaries for Linux x86_64, macOS (Apple silicon and Intel) and Windows x86_64. The installer verifies the download against the release SHA256SUMS — no sudo needed.

1

Get the binary

Run the install script, install from crates.io, or grab a release binary below. It lands in ~/.local/bin/astlens and is added to your PATH.

2

Set up your client

Run astlens install — it detects Claude Code and OpenCode and sets up each one it finds, at user scope so it applies to every project. Restart the client afterwards. astlens update keeps the binary current.

The recommended route on Linux and macOS (Git Bash on Windows). Needs curl for the binary and jq for client setup. Pin a version with --version v0.7.0.

# 1 — binary (checks SHA256SUMS, installs to ~/.local/bin)
curl -fsSL https://raw.githubusercontent.com/aeron2k4/astlens/main/scripts/install.sh | bash

# 2 — register with Claude Code / OpenCode
astlens install

astlens is published on crates.io — the same place the Rust ecosystem already trusts. First publish was v0.6.2; the current release is v0.7.0.

cargo install astlens

# then set up your client
astlens install

Every release ships three binaries plus checksums: astlens-linux, astlens-macos and astlens-windows.exe, with a SHA256SUMS file. Latest: v0.7.0 on GitHub Releases ↗

# example: Linux binary from the latest release
mkdir -p ~/.local/bin
curl -fsSL https://github.com/aeron2k4/astlens/releases/latest/download/astlens-linux -o ~/.local/bin/astlens
chmod +x ~/.local/bin/astlens
~/.local/bin/astlens install

For platforms without a prebuilt binary, such as Linux ARM. Needs Rust 1.90 or later.

git clone https://github.com/aeron2k4/astlens.git
cd astlens
cargo build --release
./target/release/astlens install

Claude Code

  • Registers the MCP server as astlens, tools always loaded
  • Writes the guard hook to ~/.claude/hooks/astlens-guard.sh and wires it in settings.json
  • Adds a short instruction block to ~/.claude/CLAUDE.md

OpenCode (v2)

  • Adds the server to mcp.servers.astlens in your OpenCode config — existing settings and comments stay untouched, original backed up first
  • Tools exposed directly as astlens_<tool>
  • Installs the guard plugin and an instruction block in AGENTS.md

The guard: agents read through astlens, not around it

The hook and plugin block whole-file reads and plain text search on source files in the workspace, and point the model at the astlens tools instead. Reads limited to 300 lines (ASTLENS_MAX_READ_LINES), non-code files, and paths outside the workspace are still allowed. Prefer no enforcement? astlens install --no-enforce registers the MCP server only.

astlens install
Set up Claude Code and/or OpenCode
astlens install --client opencode
Set up only OpenCode (or --client claude)
astlens install --no-enforce
Register the MCP server only — no hook, plugin or instructions
astlens uninstall
Undo install, remove the PATH entry and the binary
astlens update
Download the latest release over this binary, after checking it against SHA256SUMS
astlens update --check
Report whether a newer release exists, and change nothing
astlens doctor
Report the binary, where it came from and whether update can replace it
astlens --serve [ROOT]
Run the server over stdio
astlens --version
Show the version

11 languages, parsed for real

Symbols, references and outlines come from tree-sitter grammars — not regex. .h headers are parsed as C, or as C++ when C fails. Files in other languages still work as plain text for line reads, pruned reads and text edits.
