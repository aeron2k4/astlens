Navigate Codebases by Syntax Tree, Not Whole Files.

astlens is a small, fast MCP server in Rust backed by tree-sitter and LMDB. It maps repository PageRank dependencies, searches ranked symbols, filters identifier references, and returns token-budgeted code slices so AI coding agents stop reading whole files.

    astlens install
    Detect Claude Code and OpenCode, register MCP server, hook, and instructions
    
      
    astlens install --client claude
    Configure only Claude Code (or pass --client opencode)
    
      
    astlens install --no-enforce
    Register the MCP server without installing the PreToolUse read/grep guard
    
      
    astlens update [--check]
    Self-update script-installed binaries via /releases/download and SHA256SUMS
    
      
    astlens doctor
    Inspect binary path, installer owner, duplicate copies, and target asset
    
      
    astlens uninstall
    Remove client registrations, shell PATH entry, and the installed binary
    
      
    astlens --serve [ROOT]
    Run the MCP server over stdio (syncs MCP roots/list when root is omitted)
    
      
    astlens --version
    Print installed version (0.7.1)
    
    
    
  
    

  
  
    
    
    
      
    
        
    Client Integrations & Guard Architecture
    
        
    Enforces AST-first exploration inside your repository while allowing non-code files, dependency caches, and bounded line reads.
    
      
    
    
    

    
    
      
    
        
    
          
    Claude Code
    
          astlens install
        
    
        
      
          
    • Registers astlens at user scope via claude mcp add.
      • 
          
    • Installs ~/.claude/hooks/astlens-guard.sh in settings.json.
      • 
          
    • Adds navigation rules to ~/.claude/CLAUDE.md.
      • 
        
    
      
    

      
    
        
    
          
    OpenCode (v2)
    
          astlens install
        
    
        
      
          
    • Inserts mcp.servers.astlens while preserving JSONC comments and backups.
      • 
          
    • Exposes tools directly as astlens_<tool> without deferred search.
      • 
          
    • Installs astlens-guard TypeScript plugin and updates AGENTS.md.
      • 
        
    
      
    

      
    
        
    
          
    Antigravity
    
          ~/.gemini/config
        
    
        
      
          
    • Add astlens under ~/.gemini/config/mcp_config.json using stdio astlens --serve.
      • 
          
    • Supports MCP roots/list and roots/list_changed sync plus / and $HOME root guards.
      • 
          
    • Pair with plugin rules/AGENTS.md and a PreToolUse guard hook.
      • 
        
    
      
    
    
    

    
    
      
    PreToolUse Guard Policy
    
      
    The guard script blocks unbounded reads and plain-text grep inside source directories of your workspace. Line ranges of 300 lines or fewer (ASTLENS_MAX_READ_LINES), markdown/JSON/config files, piped filters (wc, sha256sum), and external dependencies stay permitted. Pass --no-enforce to skip the guard.
